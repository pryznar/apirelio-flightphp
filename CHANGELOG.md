# Changelog

## 1.0.0 - 2026-08-28

- Publish the first stable FlightPHP SDK on PHP Core 1.x.
- Support PHP 8.2 through PHP 8.5 and PHPUnit 11–13.
- Report SDK version 1.0.0 in telemetry.

## 0.1.0 - 2026-08-28

- Add FlightPHP 3 route and group middleware.
- Add matched-route, route-alias, lifecycle-error and safe request-context capture.
- Add customer and consuming-application resolvers.
- Add synchronous and file-buffered delivery backed by Apirelio PHP Core.
